# GBF-Dock v1.2.0 使用说明

## 一、快速上手（3 步）
1. 双击运行 **`GBF-Dock.exe`**，控制面板顶栏支持 **跟随电脑 / 白天 / 黑夜** 三档配色切换，并会随窗口宽度在「侧边栏 / 纯图标轨 / 底部悬浮药丸导航」间自适应变形，并硬性锁定 `480×560` 最小窗口尺寸防止缩扁回弹。
2. 前往左侧 **「网络与安全」** 页面安装本机根证书，在 Windows 安全提示弹窗中选择 **「是」**，随后**彻底关闭并重启所有浏览器窗口**（Chromium / Edge 请留意后台残留进程）。
3. 在仪表盘「接入」切换条选择加速方式（两种模式**严格互斥**，切回独立浏览器会自动关闭系统代理）：
   - **方式 A（推荐）：独立浏览器模式（免接管系统代理）**：前往左侧 **「浏览器」** 页选择 Chromium 浏览器（Chrome / Edge / Brave / 百分浏览器等）或桌面 `.lnk` 游戏快捷方式；默认 **保留原浏览器配置与登录态**，且代理参数仅当次启动有效、关闭浏览器即自动清除，**完全不改 Windows 系统代理，也不改动 FlClash 等上游代理软件**。若不想关闭正在运行的主浏览器，可切换为「独立空白配置」双开。
   - **方式 B：系统代理模式**：在仪表盘「接入」栏切到 **「系统代理」** 并开启系统代理接管开关，点击「连通检测」看到绿色「✓ 检测通过」即可启动游戏（兼容 Steam 版 GBF 及所有浏览器）。

---

## 二、从旧版 GBF Cache 迁移升级
如果你之前使用过旧版 **GBF Cache（`GBFCache.exe`）**：
1. 先退出旧版托盘程序。
2. 直接把本版解压运行即可，**无需重新安装根证书**：首次启动会自动把 `%APPDATA%\GBFCache` 中的根证书与基础设置平滑迁移到 `%APPDATA%\GBF-Dock`（原目录保留不动）。
3. 旧缓存目录的延续：
   - 可将旧版 `cache\` 文件夹复制到 `GBF-Dock.exe` 同级目录，或在设置页点击 **「更改目录」** 直接指向原 `cache\` 文件夹，或在 **「导入 / 并入旧缓存」** 中无损合并进来（旧版 `.meta_index.v1` 会自动兼容升级）。

## 三、主要功能说明

### 1. 独立加速启动与配置清理（v1.1.0 新增）
- **保留原配置（默认）**：直接沿用你所选浏览器的原有用户配置与账号登录态、扩展插件，启动前若检测到该浏览器仍在运行，会提示一键温和重启以加载 `--proxy-pac-url`。关闭该浏览器后，命令行加速参数自动失效、零残留。
- **独立空白配置（可双开）与数据清理**：若不希望重启日常使用的主浏览器，可切换为「独立空白配置」与主浏览器同时双开；在 **「配置与缓存 → 独立加速浏览器」** 卡片中可查看隔离目录磁盘占用并随时一键 **「清理独立配置数据」**，或在仪表盘/配置页点击 **「清除 / 恢复系统默认」** 取消绑定。

### 2. 上游回源与加速器兼容
- 默认 **「回源 → 自动」** 会依次检测系统现有代理 → 常见本地代理端口（Clash / FlClash / Verge / v2rayN / Sing-box / 岛风GO `8099` 等 HTTP 与 SOCKS5）→ 加速器 / TUN 虚拟网卡。
- 也可手动指定 HTTP / HTTPS / SOCKS5 上游代理或切换为「直连回源」。

### 3. 失效旧分片自动回退
- 当旧版插件/扩展请求已下线的 `prd-game-a1`~`a5` CDN 节点时，GBF-Dock 会在首次失败后自动回退到主域名（`prd-game-a-granbluefantasy.akamaized.net` / Steam 主域名）拉取并缓存，并在 30 分钟内记住失效分片以减少等待。

### 4. 局域网共享（手机 / iPad）
- 在配置页开启 **「局域网共享」** 后，可用手机或平板访问向导地址，一键下载 `ca.crt` 并配置 Wi-Fi PAC 自动代理。
- 局域网设备仅能接入静态资源缓存与正常代理联网，无法访问本机 `:8766` 控制面板或本机其他回环服务。

---

## 四、注意事项
- 退出程序请使用托盘右键 **「退出 GBF-Dock」** 或面板左下角 **「退出程序」**，程序会自动保存索引、关闭面板并还原系统代理。
- 请勿把自己的 `%APPDATA%\GBF-Dock\certs\` 目录分享给他人，该目录包含仅限你本机使用的根证书私钥（`ca.key`）。
